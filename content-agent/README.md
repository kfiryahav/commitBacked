# סוכן התוכן של כפיר 🎬

סוכן שמפיק בשבילך רילס לאינסטגרם בשיטה שלך: מוצא רילס ויראלי, מתאים אותו אליך, וכותב תסריט מוכן לאוואטר.
המטרה: **שבוע שלם של תוכן בישיבה אחת**, במקום לעשות את כל התהליך מחדש לכל סרטון.

## איך משתמשים

פותחים את Claude Code בתיקייה הזו וכותבים בעברית רגילה:

| מה אומרים | מה קורה |
|---|---|
| "הנה 10 רילס, תבדוק מה ויראלי" + קישורים | הסוכן בודק את חוק פי 5 ומוסיף לבנק |
| "תתאים לי את הרילס הזה" + קישור | תסריט מלא לאוואטר, עם 3 הוקים לבחירה |
| "בוא נכין את השבוע" | 7 תסריטים ותוכנית שבוע ב-`output/` |
| "איך היה השבוע?" + צילומי מסך של התובנות | סקירה, תובנות ושינויים לשבוע הבא |

## מבנה

```
CLAUDE.md            ← מי הסוכן ואיך הוא עובד
brand/profile.md     ← העסק, הקהל, היעד       (יש להשלים)
brand/voice.md       ← איך אתה מדבר           (יתמלא מתמלולים שלך)
memory/              ← הזיכרון: בנק ויראלי, לוג, תובנות, רעיונות
output/              ← התסריטים שהופקו, לפי שבוע
.claude/skills/      ← הסקילים: viral-hunt, adapt-reel, weekly-batch, performance-review
```

## השגרה השבועית
1. **במהלך השבוע:** כל פעם שאתה נתקל ברילס חזק, שולח קישור, והוא נכנס לבנק.
2. **ביום ראשון:** "בוא נכין את השבוע". מקבלים 7 תסריטים.
3. **אתה:** בוחר הוקים, מפיק באוואטר ברצף, ומעלה.
4. **ביום שישי:** "איך היה השבוע?", והסוכן לומד ומשתפר.
