# סקירה שבועית

## 1. איסוף נתונים
לכל רילס מהשבוע שב-`memory/content-log.md`, צריך: צפיות, לייקים, תגובות, שמירות, שיתופים,
עוקבים חדשים ו**פניות DM** (המדד הכי חשוב לעסק).

מקור הנתונים, לפי סדר עדיפות:
1. אם העמוד מחובר לחשבון מודעות ב-Meta, קרא דרך חיבור Meta Ads (`ads_get_ig_media`).
2. אחרת, בקש מכפיר צילום מסך של התובנות (Insights) מכל רילס, או טבלה.

**לא ממציאים נתונים.** מה שחסר נשאר ריק.

## 2. ניתוח
- **יחס ויראליות של כפיר עצמו:** צפיות ÷ עוקבים של כפיר. מה עבר פי 1, פי 3, פי 5?
- **דירוג** לפי: (א) פניות DM, (ב) שמירות ושיתופים, (ג) צפיות.
- **חיפוש דפוסים** לפי עמוד תוכן, סוג הוק, פורמט, אורך ויום ושעה.
- **התקדמות ליעד:** פניות ← שיחות ← לקוחות ← מחזור, מול 40,000 בחודש.

## 3. עדכון זיכרון
- `memory/content-log.md` — מלא את עמודות הביצועים.
- `memory/learnings.md` — הוסף רק תובנות שמגובות ביותר מרילס אחד, עם תאריך.
  דוגמה: `2026-11-15: הוקים בצורת שאלה ("למה אין לך מכירות?") הביאו פי 2 שמירות (3 מתוך 3 רילס).`
- אם תובנה מתהפכת, סמן את הישנה כ"בוטלה" ולא תמחק אותה.
