# מרילס ויראלי לתסריט של כפיר

## קלט
קישור לרילס, או תמלול שלו, ושורה מתאימה מ-`memory/viral-bank.md` אם קיימת.

## שלבים

### 1. תמלול ופירוק
- אם הסקיל `breakdown` זמין, הפעל אותו על הקישור כדי לקבל תמלול, הוק, מבנה וקצב.
- אם לא, בקש מכפיר את התמלול. Claude יכול לתמלל אותו אם כפיר מעלה את הסרטון.
- תרגם לעברית אם צריך.

### 2. שלד
הוצא את **השלד** של הרילס בלי התוכן. למשל:
`הוק מפתיע ← בעיה שכולם מכירים ← 3 נקודות ← טוויסט ← CTA`

### 3. התאמה
מלא את השלד מחדש מתוך העולם של כפיר:
- **מי הצופה:** מישהו שניסה איקומרס ונכשל. דבר אל הכאב שלו.
- **איזה עמוד תוכן:** בחר אחד מ-`brand/profile.md`.
- **מה כפיר יודע שהצופה לא:** הזווית של מתכנת ובונה חנויות.
- **בלי המצאות:** אין מספרים או סיפורי לקוחות שלא מופיעים בפרופיל. במקומם כתוב `[להשלים: ...]`.

### 4. כתיבה לאוואטר
- **אורך:** 30–45 שניות. בערך 80–120 מילים.
- משפטים קצרים, משפט לשורה. השורות האלה הן גם הכתוביות.
- סמן מונחים באנגלית ב-`⚠️` לבדיקת הגייה.
- התאם לקול שב-`brand/voice.md`.

### 5. שמירה ועדכון
- שמור ל-`output/YYYY-WW/NN-<נושא-קצר>.md` לפי התבנית למטה.
- עדכן את הסטטוס ב-`memory/viral-bank.md` ל-`הותאם`.
- הוסף שורה ל-`memory/content-log.md`.
