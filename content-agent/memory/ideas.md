# בנק רעיונות

רעיונות שעלו ולא נוצלו. כל רעיון: נושא, עמוד תוכן, ומה ההוק.

- למה 90% מהחנויות בשופיפיי נראות אותו דבר, ולמה זה הורג לך את ההמרות (סמכות / כאב)
- דרופשיפינג או פרייבט לייבל: איך מחליטים בדקה (מיתוס)
- מאחורי הקלעים: בונה עמוד מוצר בזמן אמת (מאחורי הקלעים)
- "שרפת כסף על מודעות?" 3 דברים לבדוק בחנות לפני שמאשימים את הפרסום (כאב)
